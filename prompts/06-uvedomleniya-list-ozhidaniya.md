# Фаза 06: Уведомления, боты, лист ожидания, открытие месяца

> Запуск: `/phase 06`. Оркестратор: **Opus**. Исполнители: `bot-builder`, `backend-builder`, `copywriter`, `qa-engineer`.
> Ворота: **G5** (токены @BotFather и MAX @MasterBot, SMS-провайдер). Без токенов — фейковые каналы и полная логика.

## Прочитать
`docs/04-avtomatizaciya-i-bot.md` целиком; `docs/02-TZ.md` §7.5, §8, §9, §12.2, §16.5; ADR 0004.

## Задачи
1. **Каналы:** `NotificationChannel` + реализации Telegram (webhook), MAX (официальный TS-клиент или HTTP API — сверь актуальную документацию), SMS (адаптер под выбранного провайдера), email (Yandex Cloud Postbox), Fake. Фолбэк критичных сообщений в SMS через 10 мин.
2. **Outbox:** `dedupeKey`, ретраи с экспонентой, журнал `Notification`, `outbox:drain` каждую минуту.
3. **Шаблоны:** `MessageTemplate` + рендер с подстановками + seed текстов из `docs/04` §4 (статус `draft` → Ирина утверждает, G3). Кнопки (inline) для Telegram и MAX.
4. **Привязка мессенджера:** одноразовый deep-link токен (TTL 24 ч) из страницы «Готово» и `/z/<token>`.
5. **Напоминания:** `reminders:enqueue` (48 ч с кнопками, 3 ч с адресом, онлайн за 1 ч); кнопки ведут в действия управления записью.
6. **Лист ожидания:** `POST /api/public/waitlist`; матчинг по `SlotFreed` + `waitlist:match` каждые 10 мин; CASCADE (≥ 24 ч, удержание 30 мин) / BROADCAST (< 24 ч); тихие часы; анти-спам; принятие предложения → HOLD → оплата; «окно уже забрали»; возврат предоплаты отменившему (ТЗ §7.4); «вы ещё ждёте?» раз в 30 дней. **Сначала тесты** на матчинг, каскад, истечение, гонку двух принятий.
7. **Открытие месяца:** `BookingRelease`, `release:open`, ранний доступ (≥ K визитов), подписка «Напомнить» (`/api/public/release/subscribe`), рассылка с учётом каналов и тихих часов (открытие в 22:00 — это явное исключение из тихих часов для подписавшихся).
8. **Админ-бот Ирины:** уведомления (новая запись, отмена, выкуп из листа, системные), сводка в 20:00 МСК, команды из `docs/04` §5.3 с подтверждением кнопкой; доступ только по `AdminUser.tgChatId`.
9. **Перенос по инициативе Ирины:** `/закрыть` или `/отпуск` на занятое время → гостям 3 варианта + возврат, Ирине — сводка выборов.
10. **Импорт канала:** бот-админ канала получает `channel_post` → черновик `Post` → Ирине [Опубликовать] [Изменить] [Не публиковать].
11. **После визита:** благодарность через 3 ч; просьба об отзыве по правилам; «пора снова» — только с рекламным согласием.

## Критерии приёмки
- Сценарии ТЗ §19 №2, 5, 7 зелёные в e2e с Fake-каналами.
- Ни одно сообщение не содержит комментарий гостя или сведения о здоровье (тест снапшотов шаблонов).
- Дубли невозможны (повторный прогон job не шлёт второе сообщение — тест dedupe).
- `compliance-reviewer` PASS (особо: согласия, минимизация, трансграничность Telegram).
