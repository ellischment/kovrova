## Задачи
1. **BookingSheet** (React-остров, ленивая загрузка): URL `/zapis?loc=&svc=&date=&tech=`; шаги Где → Что → Когда → Контакты → Оплата → Готово; прогресс «2 из 4»; «назад», Esc, фокус-ловушка, `aria-live`.
2. **Шаг «Что»:** услуги локации, цена и предоплата сразу; «Не знаю, что выбрать» → первичный приём; для постоянных гостей первичный скрыт.
3. **Шаг «Когда»:** DateStrip (индикатор «есть окна»), TimeChips по якорям, фильтр утро/день/вечер; «нет окон» → EmptySlots: [Встать в лист ожидания] + ближайшее окно в другой локации.
4. **Шаг «Контакты»:** имя, телефон (маска +7, `autocomplete`), канал напоминаний (Telegram / MAX / SMS), комментарий с подсказкой «не пишите о здоровье» и мягким предупреждением на медицинские слова, согласие PD (отдельный документ, не отмечено), согласие на рекламу (необязательно). Правила отмены — одной строкой рядом с кнопкой.
5. **Оплата:** редирект на провайдера (FakeProvider на staging) → возврат → Готово.
6. **Готово:** итог, .ics, «как добраться», кнопки подключения Telegram/MAX (deep-link токен из API), «технику можно поменять до …», ссылка «Управлять записью».
7. **Узнавание:** ссылка `/z/<token>` из сообщений открывает панель с предзаполнением («Это вы, Анна? Не вы — сменить»).
8. **Страница `/z/<token>`:** статус, перенос, отмена (с расчётом возврата до подтверждения), смена техники, записаться снова.
9. **Конфликт слота (409):** «Это окно только что заняли» + 3 альтернативы, без потери введённых данных.
10. **Переключатель моста:** `BOOKING_MODE=native` включает виджет; `dikidi` — ссылки (для отката).
11. **События аналитики** — ТЗ §14, включая `booking_abandoned(step)`.
12. **e2e (мобайл):** сценарии ТЗ §19 №1, 3 (фронтовая часть), 4, 8, 9; время сценария «новенькая» измеряется и логируется.

## Критерии приёмки
- Бюджет: чанк виджета ≤ 60 КБ gzip, главная без виджета ≤ 90 КБ JS.
- Lighthouse мобайл ≥ 95 на главной с закрытой панелью; axe 0 critical/serious с открытой панелью на каждом шаге.
- Медиана сценария «новенькая» в e2e ≤ 120 с (с учётом скриптовой задержки ввода, как у человека).
- `critic-5`: топ-3 внесены; `compliance-reviewer`: PASS.
