# Фаза 08: Продажи вне рук (сертификаты, абонементы, события, акции)

> Запуск: `/phase 08`. Исполнители: `backend-builder`, `frontend-builder`, `designer`, `copywriter`, `qa-engineer`.
> Ворота: ответы G1 по номиналам и срокам (или значения по умолчанию из `docs/08`), дизайн сертификатов утверждает Ирина.

## Прочитать
`docs/02-TZ.md` §5.5–§5.6, §7.6, §11; навыки `offers`, `pricing`, `events`, `referrals` (последний — только для документации, модуль выключен).

## Задачи
1. **Сертификаты:** покупка в один клик (`/sertifikaty`), номинал или услуга, 3 дизайна (обложки в стиле haikei «листья» и «камни»), отложенная доставка (`certificates:deliver`), PDF с QR, страница получателя, частичное списание при записи, срок действия, корректные типы чеков (аванс / зачёт) — сверить с ADR 0007.
2. **Абонементы:** продукт (N сеансов услуги, срок), покупка, списание при записи в виджете, остаток в `/z/<token>`.
3. **События и курсы:** CRUD в админке; страницы `/sobytiya/*` с `Event`-разметкой; регистрация с предоплатой, честный остаток мест, лист ожидания на событие, ссылка на онлайн-трансляцию за 1 ч.
4. **Акции:** период, цели, тип скидки, авто или промокод, лимит; ленточка на карточках, страница `/akcii` (скрыта из меню, если пусто); автоснятие.
5. **Ранний доступ постоянным** — проверить работу с фазой 06, показать гостю «вам доступно раньше».
6. **Реферальная программа** — модель данных и флаг `referrals.enabled=false`; UI не показывается (решение экономиста: включать только при свободных окнах).

## Критерии приёмки
- Покупка сертификата с мобайла ≤ 60 с (e2e), PDF корректный, доставка по расписанию работает.
- Списание сертификата или абонемента атомарно (тест гонки).
- Событие с 1 местом: две параллельные регистрации → одна успешна, вторая — в листе ожидания.
- `compliance-reviewer` PASS (нет давления и фальшивого дефицита).
