# 0006. Направление дизайна — C · Календарь
Статус: принято · Дата: 2026-09-25

## Контекст
В фазе 02 сделаны три направления (A · Книга, B · Вечер в кабинете, C · Календарь) — `docs/progress/phase-02-vybor.md`. Требование: постоянные гости должны узнать Ирину.

## Решение
Выбрано **C · Календарь**: мох как основа (`--bg #3D4E21`), песочный текст, кремовые «листы» для плотного контента, рамки дат, цвет места (олива — Лесное и онлайн, бордо — Москва), рукописный месяц (Marck Script, только месяцы и одно слово-акцент), Geologica для всего остального. Темы: moss (по умолчанию), night, cream. Токены — `design/directions/c/tokens.css`.

## Дополнение 2026-09-25: основа — бежевая
По решению заказчицы основой стало **бежевое оформление** (тема cream: фон `#F6E7D2`, текст `#1E2113`, кнопки мох `#3D4E21` с песочным текстом, рукописный акцент бордо). Мох и ночь остаются темами на выбор. Цвета мест не меняются: олива (на бежевом — `#5E7338`) = Лесное и онлайн, бордо = Москва. В версии агентов выбор выделения идёт через токены `--pick`/`--pick-ink`, в версии Claude Design — класс `.c-root.cream`.

## Последствия
- Календарь — и образ, и механика записи: расписание хранится **по датам** с цветом локации (ТЗ §7.1 уточняется: шаблон недели — только автозаполнение).
- Тепло закрываем фото Ирины и её текстами; из A берём главы «Об Ирине» и «Если вы впервые», из B — тёплую съёмку.
- Открытые правки из ревью C: короткие названия услуг для таблиц на 360 px; календарь на главной — только реальные дни из админки.
- Невыбранные A и B остаются в `design/directions/` как архив.

## Как откатить
Токены изолированы в одном файле; смена направления = замена `tokens.css` и перевёрстка компонентов.
