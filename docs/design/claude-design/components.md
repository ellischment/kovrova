# Компоненты направления C · Календарь (фаза 02b)

Источник стилей: `design/directions/c/base.css` (шрифты, токены тем moss / night / cream / auto, компоненты, десктоп через container queries от 900 px). Макеты: `design/directions/c/canvas/*.dc.html` (холст Claude Design), статичные страницы: `design/directions/c/pages/*.html`, скриншоты: `docs/progress/screens/phase-02b/`.

Правила для переноса в Astro/React: один компонент = один класс из списка ниже, состояния задаются модификаторами (`.on`, `.off`, `.les`, `.msk`, `.full`, `.sel`, `.unk`, `.err`), цвета только через переменные темы.

## Основа
| Компонент | Класс | Состояния | Где |
|---|---|---|---|
| Корень страницы | `.c-root` + тема | moss, `night`, `cream`, `auto` (по системной теме) | все |
| Контейнер ширины | `.w` | 20 px поля, от 900 px 64 px | все |
| Секция | `.sec` | отступ 56, от 900 px 104 | все |
| Стек / ряд | `.st .g*`, `.row`, `.between`, `.cols2/3` | | все |
| Десктоп-сетки | `.d-2 .d-2c .d-3 .d-4 .d-57 .d-75 .d-48 .vgrid` | колонки только от 900 px | все |

## Типографика
`.lbl` (надпись капсом), `.h1` 44→84, `.h1s` 34→64 (длинные названия), `.h2` 34→56, `.h3`, `.h4`, `.lead`, `.p`, `.small`, `.xs`, `.quote`, `.prose` (длинный текст), `.hand` (Marck Script, только месяцы и одно слово-акцент), `.num`.

## Действия
| Компонент | Класс | Состояния |
|---|---|---|
| Главная кнопка | `.btn`, `.btn-s` | обычная, фокус (3 px обводка), внутри `.sheet` и `.field` меняет цвет сама |
| Вторичная кнопка | `.btn2` | обычная, фокус |
| Иконка-кнопка 44×44 | `.ibtn` | нужен `aria-label` |
| Ссылка | `.link` | в тексте высота строки, отдельно 44 px |
| Рамка-выбор | `.fr` | `.on` выбрано, `.off` занято (пунктир, зачёркнуто), `.les` рамка Лесного, `.msk` заливка Москвы, `.tall` две строки |
| Плитка намерения | `.tile` | ссылка на цены с фильтром |
| Сегменты | `.seg` | `.on` |

## Календарь (главный узнаваемый элемент)
| Компонент | Класс | Состояния |
|---|---|---|
| Сетка месяца | `.cal`, `.wd` | 7 колонок, `role="grid"` |
| День | `.day` | `.les` оливковая рамка (Лесное и онлайн), `.msk` бордовая заливка (Москва), `.full` пунктир и зачёркивание (всё занято), `.sel` выбран, без класса приёма нет |
| Легенда | `.legend`, `.sw.les/.msk/.full` | |
| Время | `.fr` в `.cols3` | якорные старты, `.off` для занятых |
| Дата-плашка | рамка 3 px `--les` + `.hand` месяц | «Готово», «Моя запись», событие, предложение из листа |

## Листы и таблицы
| Компонент | Класс | Состояния |
|---|---|---|
| Кремовый лист | `.sheet` | для плотного текста, таблиц, итогов |
| Цены «вид × место» | сетка из `div` + `.pc` | `.pc` цена-кнопка, `.unk` цена неизвестна, `.no` не проводится |
| Малая таблица | `.mxg .mxr .mxh` | |
| Ключ-значение | `.kv` | |
| Цветное поле | `.field` | бордо, текст кремовый |
| Полоса | `.band` | тёмный мох под календарём |

## Формы
`.fld` + `label`, `.inp` (`.err` + `.errmsg` рядом, `aria-invalid`, `aria-describedby`), `textarea.inp`, `.cb` (чекбокс, текст в `span`; согласие отдельной неотмеченной галочкой), `.srch` (поиск), `.seg`.

## Сообщения и состояния
`.alert` (ошибка, конфликт, мест нет, `role="alert"`), `.ok` (успех, `role="status"`), `.note` (пояснение), `.sk` (скелет загрузки, `aria-busy`), `.ph` (место для фото с подписью, что снять), `.tag`, `details.acc` (вопросы, «+» и «−» сами).

## Каркас
`.hdr` + `.logo` + `.nav` (от 900 px), `.status` (строка «запись открыта»), `.crumbs`, `.ftr` (дисклеймер обязателен), `.bar` (нижняя панель на телефоне: написать, позвонить, записаться; на десктопе скрыта).

## Запись
`.panel` (на десктопе `.d-sheet`, лист 560 px по центру), `.ptop`, `.steps` (`.done` пройдено, `.on` текущий), `.pbody`, `.pfoot`, `.q`, `.opt` (`.les`, `.msk`, `.on`). Состояния: где, что, когда, нет окон, окно заняли, ранний доступ, контакты с ошибкой, оплата не прошла, готово.

## Кабинет Ирины
`.tabs` (5 вкладок), `.slot` + `.tm` (`.free`, `.msk`), `.cell` (`.unk`, `.hid` скрыто, `.focus`), `.bars` (отчёт), `.chat .bub .mb` (превью сообщения), `.mail`.

## Доступность
Контраст всех пар текст/фон ≥ 4.5:1 (рассчитано скриптом, минимум 5.6:1 для приглушённого текста на мху), цели касания ≥ 44 px, видимый фокус 3 px, у иконок `aria-label`, календарь с `aria-label` на каждом дне. axe на живой вёрстке прогнать в фазе 03.
