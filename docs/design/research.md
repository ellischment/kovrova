# Исследование для фазы 02: референсы, пути записи, мудборды

Сделано 24–25 сентября 2026. Макеты всех трёх направлений лежат на холсте «Ирина Коврова · три направления дизайна» (Claude Design). Ссылки, которые проверены поиском, отмечены «✓». Остальное взято из общеизвестной практики, их стоит открыть и посмотреть глазами.

## 1. Кто она (бриф личности бренда)

Из постов, а не из слова «массаж»:

- Честная и думающая. Длинные рассуждения про экономику прайса, этику кейсов, общество.
- Бережная, без нажима. «Силу воздействия вы регулируете сами», «меняем жизни постепенно, безопасным путём».
- Холистичная. Тело и психика вместе, методы как набор инструментов.
- Тёплое живое пространство. Кабинет у леса, синие шторы, бордовая форма, масла, камни, пледы.
- Анти-хайп. Никаких «до/после», таймеров, «успей».
- Свой визуальный язык уже есть: сторис-календарь с рамками дат (олива: Лесное и онлайн, бордо: Москва), рукописное название месяца.

### Три оси характера и положение направлений

| Ось | A · Книга | B · Вечер в кабинете | C · Календарь |
|---|---|---|---|
| тёплый ↔ строгий | ближе к строгому | тёплый | посередине, чуть строже |
| редакционный ↔ уютный | редакционный | уютный | посередине |
| природный ↔ городской | посередине | природный | городской |
| светлый ↔ тёмный по умолчанию | светлый (есть ночная тема) | тёмный (есть дневная) | мох, средне-тёмный (есть ночная и кремовая) |

## 3. Пути записи: что устроено хорошо

| Сервис | Выбор услуги | Выбор времени | Пустое состояние | Вывод для нас |
|---|---|---|---|---|
| Cal.com | Одна услуга на ссылку | Месяц + слоты рядом, недоступные дни приглушены | «Нет доступного времени», без выхода | Берём месяц с отмеченными днями, добавляем выход (лист ожидания) |
| YCLIENTS | Категории → услуги, порядок шагов настраивается | Лента дней + слоты | Лист ожидания есть, но спрятан в админке | Лист ожидания выносим в сам тупик, одним экраном |
| Jane App | Сначала дисциплина, затем «первичный / повторный» | Практик + список слотов | Предлагает другие локации | Берём «первый раз» как отдельный вход и соседнюю локацию в тупике |
| Fresha | Категории, «популярное» | Лента дат + время по частям дня | Предлагает другие даты | Фильтр «утро / день / вечер» |
| DIKIDI (сейчас) | Место → 68 услуг | Календарь + время | «Позвонить» | Анти-пример |

## 4. Мудборды словами

### A · Книга
- Цвет: тёплая бумага #F4EEE3, чернила #1D1A15, бордо #7D1F2C для номеров глав и ссылок, мох #3D4E21 для главной кнопки. Ночью: бумага #17150F, песок как кнопка.
- Фактура: бумага без текстур, тонкие линейки, отточие в прайсе.
- Свет: ровный дневной, как в читальном зале.
- Шрифты: Literata (заголовки и текст, книжная кириллица), Golos Text (интерфейс и цифры).
- Композиция: одна колонка на телефоне, на десктопе поля с примечаниями слева, иллюстрации с подписями «Илл. 1».

### B · Вечер в кабинете
- Цвет: синие шторы #111822, песок #F2DCB9 для кнопок, мох и бордо цветными плашками, олива и бордо-светлый как метки мест.
- Фактура: мягкие скругления, плотные тёмные поверхности, фото с тёплым светом.
- Свет: вечерняя лампа, тёмный фон, лицо и руки освещены.
- Шрифты: Bona Nova курсивом для заголовков, Onest для текста.
- Композиция: фото на всю ширину, один главный жест на экран, запись как лист, поднимающийся снизу.

### C · Календарь (по отзыву: предпочтительный)
- Цвет: мох #3D4E21 как основа всего сайта, песочный текст #F2DCB9, крем #F6E7D2 для плотных таблиц, бордо #7E1F2A для Москвы и акцентных полей. Ночью: #14170E.
- Фактура: рамки 2 px с почти прямыми углами, пунктир для «занято», сплошная заливка бордо для московских дней.
- Свет: не важен, держится на цвете и графике.
- Шрифты: Geologica (всё, от 350 до 800), Marck Script только для названий месяцев и одного слова-акцента.
- Композиция: строгая сетка, календарь месяца как центр главной и шага «Когда», прайс как таблица «вид × место».
