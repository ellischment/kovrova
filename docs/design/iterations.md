# Лог итераций, фаза 02

Макеты сделаны на холсте Claude Design («Ирина Коврова · три направления дизайна»), а не HTML-прототипами в `design/directions/`. Поэтому шаг «скриншоты Playwright 375/1280 после каждой итерации» пока не выполнен: холст рендерится только в браузере Ирины и Василисы. Когда направление выбрано, его экраны переносятся в `design/directions/<x>/` и там проходят 3 итерации со скриншотами и axe.

## Итерация 1 (24.09)
- Выведен бриф личности и 3 оси, собраны 3 направления (A · Книга, B · Вечер в кабинете, C · Календарь).
- Каталог: 13 семейств × 3 места × длительности = 61 вариант. Известные цены из DIKIDI (5 500 / 5 500 / 4 000 ₽), остальное [?].
- Шрифты загружены на свой сервер (Fontsource, подмножества latin + cyrillic + ₽). Ни одного запроса к Google.
- Контраст всех пар текст/фон посчитан скриптом, минимум 4.5:1 для текста (см. `phase-02-vybor.md`).

## Итерация 2 (24.09, самокритика по коду)
- Убраны выдуманные детали из текстов: «чай после сеанса», «многие гости сочетают», «лучше спать». Вместо них [?] для Ирины.
- В админке прочерк в пустых ячейках заменён на слово «нет».
- Фото кабинета обрезано так, чтобы лицо гостьи не попадало в кадр (согласия на распространение пока нет).

## Итерация 3 (24–25.09, отзыв Василисы: «этот стиль я бы везде делала»)
- Направление C перестроено: мох стал основой всего сайта, а не акцентом. Песочный текст, Geologica, рукописный месяц. Крем остаётся для плотных таблиц.
- Москва на мху: вместо бордовой рамки (не видна на мху) сплошная бордовая заливка с кремовым текстом 8.2:1. Лесное: светло-оливковая рамка 5.1:1.
- Добавлены темы C: мох (по умолчанию), «олива ночью», кремовая.
- В админке C появился экран «Месяц»: дни раскрашиваются по месту, как в её сторис, и там же поле «Открыть запись: дата и время».
