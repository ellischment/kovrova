# Компоненты публичной части (направление C · Календарь)

> Источник вёрстки: `design/directions/c/base.css` (владелец — designer) + `design/directions/c/app.js`.
> Токены: `design/directions/c/tokens.css` (primitive → semantic, темы moss/night/cream).
> Для переноса в Astro/React: каждый компонент ниже — кандидат в отдельный `.astro`/`.tsx`, стили — в CSS-модуль или сохранить как есть с CSS custom properties.

## Структурные
| Компонент | Класс | Состояния | Заметки |

## Правила использования (соблюдены во всех 24 HTML)
- Одна основная (`.btn-primary`) кнопка на секцию/экран, остальные действия — `.btn-secondary`/`.btn-text`.
- Дисклеймер «Услуги не являются медицинскими…» — в футере (все страницы) и дополнительно на страницах услуг/первичного приёма/каталога.
- Все `[?]`-места — видимый текст с пометкой, не скрытый комментарий, чтобы редактор контента увидел пробел сразу.
- Цветовой код места (олива/бордо/пунктир-онлайн) одинаков в календаре, таблице цен и на страницах локаций — единая система считывания.
- Контраст: кнопки внутри кремовых `.sheet` явно переопределены (`.sheet a.btn-primary`, `.sheet .btn-secondary`), чтобы не наследовать светлый `--text` страницы поверх светлого фона листа (это была найдена и исправлена реальная ошибка контраста в ходе тестирования, см. отчёт фазы).
- Все интерактивные элементы (радиокнопки, чекбоксы, вкладки локаций, чипы фильтров, кнопки темы) ≥ 44px в высоту строки или явно увеличены (`.field input[type="radio"]` 24px + `min-height:44px` на обёртке-label).
