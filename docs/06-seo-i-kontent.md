# 06. SEO, локальный поиск и контент

> Поиск в РФ — это прежде всего **Яндекс** (органика + Карты), затем ИИ-ответы (Алиса, Нейро), затем Google.
> Для местной услуги **карточка в Картах важнее сайта**, а сайт — это страница, куда карточка ведёт и где закрывается запись.

---

## 1. Семантическое ядро (гипотезы → проверить в Яндекс Вордстате)

| Кластер | Примеры запросов | Страница |
|---|---|---|
| Массаж локально | массаж Мисайлово; массаж Пригород Лесное; массаж Видное; массаж рядом; массажист на дом [нет — исключить] | `/lesnoe`, `/uslugi/massazh/` |
| Виды массажа | лимфодренажный массаж Мисайлово; стоун-массаж; классический массаж спины; массаж лица и шеи | `/uslugi/massazh/<техника>` |
| Остеопрактика | остеопрактика; остеопрактик Видное; мягкие мануальные техники | `/uslugi/osteopraktika` |
| Психосоматика | психосоматика консультация онлайн; психосоматика телесная; метафорические карты консультация | `/uslugi/psihosomatika`, `/online` |
| Биодинамика | биодинамика для грудничков; краниосакральная биодинамика [проверить формулировки] | `/uslugi/biodinamika` |
| БЭМ | биоэнергорегуляция массаж; массаж перчатками | `/uslugi/massazh/bem-bioenergoregulyaciya` |

| Бренд | Ирина Протченко; Протченко массаж | `/`, `/ob-irine` |

> Задача для Manus или SEO-агента: собрать частотность в Вордстате (регион «Москва и область»), конкурентов в выдаче и Картах, их цены и форматы. Промпт — `prompts/manus-research.md`.

**Осторожно с медицинскими запросами** («лечение грыжи массаж», «остеопат») — не продвигаемся по ним (см. словарь «не медицина»).

## 2. Требования к страницам
- Один кластер — одна страница; H1 содержит главный запрос естественно («Лимфодренажный массаж в Пригороде Лесное»).
- `title` ≤ 60 символов, `description` ≤ 160, уникальные.
- Минимум 400–800 слов полезного текста на страницах услуг: как проходит, кому подходит, когда не стоит, FAQ. **Никаких «SEO-простыней»**, генерированных без редактуры.
- Внутренние ссылки: услуга ↔ локация ↔ техники ↔ запись; хлебные крошки.
- **Не делаем программатик-страниц «услуга × город»** для городов, где Ирина не работает: тонкий контент и риск фильтров.
- Живые блоки «ближайшие окна» рендерятся на клиенте (остров), чтобы HTML оставался статичным и кэшируемым.

## 3. Микроразметка (JSON-LD, пример для Лесного)
```json
{
  "@context": "https://schema.org",
  "@type": "HealthAndBeautyBusiness",
  "@id": "https://<домен>/lesnoe#business",
  "name": "Ирина Протченко — массаж и остеопрактика в Пригороде Лесное",
  "url": "https://<домен>/lesnoe",
  "telephone": "+7-991-606-14-58",
  "image": "https://<домен>/img/lesnoe-cover.jpg",
  "address": {"@type": "PostalAddress", "streetAddress": "ул. Героя России Филиппова, 8",
              "addressLocality": "Мисайлово", "addressRegion": "Московская область", "addressCountry": "RU"},
  "geo": {"@type": "GeoCoordinates", "latitude": 55.552974, "longitude": 37.807862},
  "openingHoursSpecification": [{"@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Tuesday","Wednesday","Saturday","Sunday"], "opens": "09:00", "closes": "21:00"}],
  "founder": {"@type": "Person", "name": "Ирина Протченко", "@id": "https://<домен>/ob-irine#person"},
  "makesOffer": [{"@type": "Offer", "priceCurrency": "RUB", "price": "5500",
      "itemOffered": {"@type": "Service", "name": "Массаж 90 минут"}}],
  "sameAs": ["https://t.me/<канал>", "https://yandex.ru/maps/org/<id>", "https://dikidi.net/2070240"]
}
```
Также: `Person` (Ирина: обучение как `hasCredential`), `Service` на страницах услуг, `Event` для мероприятий (с `offers`, `eventAttendanceMode`), `FAQPage`, `BreadcrumbList`. **`AggregateRating` о себе не размечаем.**

## 4. Локальный поиск (делается в фазе Б, без сайта)
1. **Яндекс Бизнес:** карточка на каждую локацию; категории «Массажный салон» / «Массажист» [подобрать]; фото (из съёмки); услуги с ценами; ссылка на запись → сайт `/zapis?loc=lesnoe&utm_source=yandex_maps`; ответы на отзывы.
2. **2ГИС:** то же.
3. **Яндекс Вебмастер:** подтверждение сайта, sitemap, регион сайта «Московская область», проверка индексации.
4. **Единые NAP-данные** (название, адрес, телефон) — везде одинаково.
5. Просить отзыв на Картах в сообщении после 2-го визита (шаблон в 04). Ссылка на Карты — одна из кнопок.

## 5. ИИ-поиск (AEO / GEO)
- `llms.txt` в корне: кто Ирина, форматы, локации, цены (ссылка на страницу), правила записи, чего она **не** делает (не медицина).
- Ясные фактические блоки на страницах («Длительность: 90 мин. Цена в Лесном: 5 500 ₽. Где: …»), FAQ с прямыми ответами.
- Навык `ai-seo` из marketingskills — на фазе 8.

## 6. Контент-движок из Telegram-канала
Ирина уже пишет длинные вдумчивые посты: о прайсе, о подходе, о БЭМ, о кейсах. Это лучший SEO-контент, который невозможно подделать.
- Импорт постов → черновик заметки → одна кнопка «Опубликовать» (см. ТЗ 12.2).
- Агент-редактор (по запросу Ирины) предлагает заголовок, `description`, внутренние ссылки на услуги, **не меняя её текст**.
- Посты о новых методиках (БЭМ) → основа страницы услуги.

## 7. Аналитика
| Инструмент | Что | Согласие |
|---|---|---|
| Umami (self-host, РФ) | просмотры, события воронки, UTM | не требуется (без cookie, без IP) — подтвердить у юриста |
| Яндекс Метрика | карта кликов, цели, Директ (если будет) | только после согласия; Вебвизор выключен |
| Внутренние отчёты админки | загрузка, отмены, выкупы из листа, выручка | — |

UTM-разметка для всех внешних ссылок: канал (`utm_source=telegram&utm_medium=channel&utm_campaign=release_nov`), Карты, DIKIDI, визитки (QR).
