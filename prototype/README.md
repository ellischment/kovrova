Статические страницы: открыть в браузере без сервера и сборки.

| Файл | Что показывает |
|---|---|
| `index.html` | Главная (mobile-first) и **работающая панель записи**: Где → Что → Когда → Контакты → предоплата → Готово; «нет окон» → лист ожидания; «Напомнить об открытии записи»; согласие 152-ФЗ; мягкое предупреждение о сведениях о здоровье; .ics для календаря |
| `admin.html` | Кабинет Ирины на телефоне: «Сегодня», матрица цен, лист ожидания, сообщения бота (что видит гостья / что видит Ирина) |

- Данные демонстрационные; `[?]` — факт нужно подтвердить у Ирины (`docs/08-voprosy-k-irine.md`).
- Ничего никуда не отправляется. События аналитики пишутся в консоль браузера (`[analytics] booking_started …`), это план событий из ТЗ §14.
- Шрифты Lora и Manrope лежат локально (`fonts/`, лицензия OFL), запросов к Google нет.
- Фото подгружаются из публичного профиля DIKIDI (это контент Ирины); если недоступны — показываются заглушки. В продукте будут фото со съёмки по брифу `docs/03` §8.
- Это **не** код продакшена: агенты переносят подход и логику, а не файлы (см. `prompts/02-dizajn.md`, `prompts/05-vidzhet-zapisi.md`).

Проверено: Chromium, iPhone SE (375×667) и 1280×800 — путь записи и лист ожидания проходятся, ошибок JS нет, модальных окон без действия пользователя нет.
