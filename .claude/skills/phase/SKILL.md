# /phase: цикл фазы

Аргумент: номер фазы `NN` (если не указан — возьми «Следующая» из `docs/progress/STATUS.md`).

## 0. Загрузка контекста (экономно)
1. Прочитай `CLAUDE.md`, `docs/progress/STATUS.md`, `docs/HUMAN-TODO.md`, затем `prompts/NN-*.md`.
2. Разделы ТЗ и документов читай **только те, на которые ссылается промпт фазы**.
3. Проверь человеческие ворота фазы. Если нужный ответ отсутствует и без него нельзя сделать даже часть работы — запиши вопрос в `docs/HUMAN-TODO.md` и остановись с коротким отчётом. Если можно работать на значениях по умолчанию, работай, помечая `[?]`.

## 1. Разведка
Вызови агента `scout` с задачей фазы и известными точками входа. Работай по его карте, повторный широкий поиск — только если карта неполна.

## 2. План
Создай задачи (TaskCreate): каждая = результат + критерии приёмки (из промпта фазы и ТЗ §19) + исполнитель-агент. Отметь, какие задачи независимы (их можно делать параллельно, в отдельных worktree).

## 3. Сборка
Делегируй профильным агентам (`architect` → `backend-builder` / `frontend-builder` / `bot-builder` / `designer` / `copywriter` / `seo-specialist`). Бриф: цель, файлы, критерии, чего не трогать, какие тесты написать.

## 4. Проверка
`qa-engineer`: команды проверки, e2e мобайл, для UI — Lighthouse, axe, сетевой аудит и аудит попапов.

## 5. Ревью (параллельно)
- `compliance-reviewer` — на весь diff фазы (всегда).
- `critic-5` — если фаза меняет UX или тексты.

## 6. Исправления
BLOCKER и MAJOR исправляются, затем снова шаги 4–5. **Не больше 3 итераций на задачу.** Не сошлось — опиши в `docs/HUMAN-TODO.md` (что, почему, варианты решения) и переходи к следующей задаче.

## 7. Ворота
Вызови навык `done-check`. Всё зелёное — продолжай.

## 8. Коммит
Conventional Commits на английском, по одной логической единице. Push в рабочую ветку. PR — если так просит пользователь или промпт фазы.

## 9. Память
Обнови `docs/progress/STATUS.md`: сделано (с коммитами), следующая фаза и задача, блокеры. Новые вопросы людям — в `docs/HUMAN-TODO.md`. Архитектурные решения — ADR в `docs/adr/`.

## Итоговый ответ пользователю (коротко)
Что готово и как проверить; что ждёт людей (со ссылкой на пункт HUMAN-TODO); что дальше (`/phase NN+1`).
