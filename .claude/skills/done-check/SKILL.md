# /done-check: определение готовности

Пройди список и для каждого пункта дай ✅ / ❌ / n/a с доказательством (команда и её результат или путь к файлу).

## Код
- [ ] Typecheck и lint затронутых пакетов — без ошибок.
- [ ] Unit-тесты затронутых модулей — зелёные; новые правила покрыты тестами.
- [ ] e2e сценариев задачи (мобайл) — зелёные.
- [ ] Нет секретов в diff (`git diff | rg -i "(api[_-]?key|token|secret|password)\s*[:=]"` — только плейсхолдеры).

## Продукт
- [ ] Критерии приёмки задачи (из промпта фазы и ТЗ §19) выполнены — перечисли каждый.
- [ ] Для UI: Lighthouse мобайл ≥ 95/95/95 на затронутых страницах; axe 0 critical/serious.
- [ ] Сетевой аудит: 0 запросов к Google, Meta и прочим трекерам.
- [ ] Аудит попапов: ни одного диалога без действия пользователя.

## Соответствие
- [ ] `compliance-reviewer`: VERDICT PASS (или только MINOR).
- [ ] Тексты: словарь «не медицина» соблюдён; факты не выдуманы (неизвестное помечено `[?]` и есть в HUMAN-TODO).

## Документация и память
- [ ] Обновлены `CLAUDE.md` (команды, если появились), ADR (если было решение), `docs/progress/STATUS.md`.
- [ ] Вопросы людям — в `docs/HUMAN-TODO.md`.

Если есть ❌ — задача НЕ готова: верни её в цикл исправлений (≤ 3 итераций) или эскалируй.
