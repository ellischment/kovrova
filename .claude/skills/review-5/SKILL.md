# /review-5

1. Определи объект: аргумент (путь / URL-путь страницы) или `git diff` относительно базовой ветки.
2. Если объект — UI и есть запущенный dev-сервер или прототип, сними скриншоты мобайла (375×667) и десктопа (1280×800) через Playwright в `docs/progress/screens/review-<дата>/`.
3. Параллельно вызови:
   - `critic-5` — с diff, скриншотами и ссылкой на `docs/01-analiz-5-perspektiv.md`;
   - `compliance-reviewer` — с diff.
4. Сведи результат в один ответ: вердикт соответствия, топ-3 изменения по «эффект / усилие», остальное — списком.
5. Спроси пользователя, применить ли топ-3. Если применять — это отдельная задача через `/phase` или прямые правки по его команде.
